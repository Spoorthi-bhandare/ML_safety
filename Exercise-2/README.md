# Exercise 2

Machine Learning Safety – Exercise 2.

This exercise covers safety analysis of an autonomous driving system using
safety vocabulary and STPA concepts.

## Topics Covered

- Safety vocabulary
- Losses
- Hazards
- Risk
- Operational Design Domain (ODD)
- Control structure
- Unsafe Control Actions (UCAs)
- Safety constraints
- Causal loss scenarios
- Mapping constraints to evidence

## System

The analysis focuses on a CARLA autonomous driving system, with particular
attention to pedestrian detection and its safety implications.
